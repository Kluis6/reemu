# Screenshots de referência — modo Xbox

Coloque aqui as capturas de tela do **modo Xbox** (app Xbox no Windows 11) que
servem de referência visual pro frontend do ReEmu.

Sugestão de nomes:

| arquivo | o que mostra |
|---|---|
| `01-home-hero-shelves.png` | Home: hero grande + prateleiras horizontais de cartões |
| `02-my-games-grid.png` | "Meus jogos": chips de filtro, contagem, grade de cartões |
| `03-cloud.png` | Aba de streaming: hero + prateleiras |
| `04-store.png` | Store: hero + botões de atalho |
| `05-rail.png` | Detalhe do rail de ícones (ativo vs inativo) |

Esses arquivos **não são versionados** (`.gitignore`) — são capturas de um
produto de terceiros, guardadas só como referência local de design. O
[documento](../xbox-mode-reference.md) descreve cada padrão por escrito para
quem não tiver as imagens.
