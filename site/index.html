ReEmu Código no GitHub

Seus jogos clássicos, com cara de console.

Frontend de emulação com cores libretro: biblioteca com capas, shaders CRT, molduras, save states com miniatura e navegação completa pelo controle. Grátis e de código aberto (MIT).

Procurando a versão mais recente…

Depois de instalado, o ReEmu avisa sozinho quando sai versão nova e se atualiza pelo próprio app.

Todas as versões

ReEmu é distribuído sob a licença MIT. Os cores libretro têm licenças próprias e são baixados pelo app. Jogos e BIOS não acompanham o ReEmu.
